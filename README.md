Price Tracker
A simple Python application to scrape book prices from Books to Scrape, convert GBP prices to KES, and manage the data via a terminal menu.

Features
Scrape book titles and prices from the website
Convert GBP prices to Kenyan Shillings (KES) using real-time exchange rates
Display data in a clean table format
Save data to a CSV file with timestamps
Interactive terminal menu for easy operation
Installation
Clone the repository:

Usage
Run the application:

python scraper.py
Use the menu options:

Scrape products - Fetch book data from the website
Convert currency - Convert prices to KES
View products - Display data in a table
Save to CSV - Export data to products.csv
Exit - Quit the application
Requirements
Python 3.6+
Internet connection for scraping and exchange rate API
